# Tic-Tac-Toe Game

A two-player Tic-Tac-Toe game made with HTML, CSS, and JavaScript.

## Files
- `index.html` — game structure
- `style.css` — styling and responsive layout
- `script.js` — turns, win/draw detection, and restart logic

## How to Run
1. Extract the ZIP file.
2. Open `index.html` in a modern web browser.
3. Player X goes first. Players take turns clicking empty cells.
4. Use **Restart Game** to begin a new round.

No installation or internet connection is required.
